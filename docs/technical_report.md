# UR20 电池螺钉拆卸系统：技术报告

**版本日期：2026-11-08**  
**范围：** 本文描述仓库当前实现的 MuJoCo UR20 场景、视觉估计、策略接口、视觉/力觉闭环控制与评测方式。实现事实以源码和场景为准；实验数字仅引用仓库现存结果，不将单次成功外推为统计结论。

## 摘要

本项目构建了一个可复现的 UR20 电池螺钉拆卸任务：策略从双 RGB 视角观察场景，通过受约束工具调用完成末端移动、套筒对准与接合，最后旋转并按螺旋关系提取 M6 螺钉。系统将高层模型决策与确定性的机器人执行器分离，结合基于 HSV 连通域的免训练视觉线索、相机几何反投影、末端力/力矩传感和顺应式搜索，形成可记录、可复播的闭环基准。MuJoCo 场景以理想螺旋副模拟旋转—进给关系，并以接触和稳定接合约束任务成功。现有记录展示了单状态端到端成功及确定性重放成功；尚不足以支持跨 10 个状态或跨模型的统计性能声明。

## 1. 问题定义与贡献

给定电池包上的目标 M6 外六角螺钉、UR20 机械臂及固定安装的电动螺丝刀/套筒，系统需要：

1. 从 `agentview` 与 `wristview` 图像定位目标螺钉及工具相对偏差；
2. 将工具移至目标上方并建立横向对准；
3. 在接触条件下通过顺应运动和螺旋搜索找到套筒可接合姿态；
4. 确认稳定接合后转动套筒，达到预定的螺钉轴向提取量；
5. 记录策略调用、动作、传感状态、轨迹和视频，支持结果复核。

项目的工程贡献是一个组合式评测框架，而非单一新学习算法：MuJoCo 任务环境、显式高层工具 API、免训练视觉测量、力觉顺应控制与触觉搜索、可重放 rollout，以及将成功定义为真实仿真状态变化的任务契约。

## 2. 系统架构

执行链路如下：

```text
MuJoCo scene
  → simulation worker (JSON-lines RPC)
  → robot adapter / observation
  → RGB visual estimator + optional force/tactile state
  → policy client (tool-call interface)
  → action mapping and safety gates
  → Cartesian / compliant / spiral / socket-turn controller
  → MuJoCo step and evaluation
  → JSONL, summary, trajectory, video artifacts
```

### 2.1 仿真与机器人适配

`assets/ur20_screw_station/scene.xml` 描述 UR20、刚性安装的末端工具、电池、目标螺钉、碰撞几何、传感器、相机和执行器。仿真 worker 隔离 MuJoCo 进程，通过 JSON-lines 请求/响应传递图像、状态和动作；`simulation/robot.py` 将 worker 暴露为统一的场景/观测/动作接口。策略可见的图像是 `agentview` 与 `wristview`；用于评估套筒接触、轴向误差和有效接合的内部状态不作为策略输入。

观测状态采用结构化字段承载末端位置、关节状态、速度及可选的补偿力/力矩和螺旋搜索触觉摘要。每个动作返回观测、执行信息及终止状态，便于将策略决定与环境事实分开审计。

### 2.2 策略与工具契约

高层策略以工具调用而非直接关节力矩控制环境。主要动作包括：

- `move_to`: 对指定笛卡尔坐标轴给出目标，其余轴保持当前值；
- `spiral_search`: 仅在测得轴向接触后启动接合搜索；
- `turn_socket`: 仅在触觉接合状态确认后启动套筒旋转；
- `done`: 结束策略交互，但不等价于任务成功。

映射层对动作参数做类型/必需字段检查，并在条件不满足时拒绝动作且不推进仿真。笛卡尔目标有单步增量限制；对齐锁定、视觉置信度和力觉接触状态共同约束后续运动。模型调用预算器记录请求次数、估算用量和成本，并在超限时于发请求前阻断调用。

## 3. 场景模型与任务物理

### 3.1 螺钉与套筒

目标为 M6 螺钉，视觉网格尖端位于局部 `z=0`，头部高度约 21 mm。螺钉由绕 `z` 的转动关节和沿 `z` 的滑动关节构成。场景通过 MuJoCo equality joint 约束旋转角与轴向位移：

\[
q_z = c + k\theta, \qquad k = 1.59155\times10^{-4}\;\mathrm{m/rad}.
\]

对应 M6 粗牙 1 mm 螺距：

\[
k = \frac{p}{2\pi} = \frac{0.001}{2\pi}\;\mathrm{m/rad}, \qquad
\Delta z = \frac{p}{2\pi}\Delta\theta.
\]

按该模型，完整旋出 21 mm 需要约 21 圈（7560°）；场景执行和终止以测得轴向提取量为准，而非仅以控制器结束为准。旋转和轴向自由度通过 equality 约束耦合，阻尼及 armature 用于仿真数值稳定与低质量螺钉的动态响应。

套筒采用实体碰撞面表达 10 mm 对边六角配合，头部接触、径向/轴向误差和稳定持续步数用于判断是否有效套接。项目不模拟真实螺纹表面、螺纹摩擦、材料屈服或电池壳体形变；理想螺旋关系是任务动力学代理模型。

### 3.2 成功条件

成功不是“策略调用 done”或 rollout 正常退出。环境需要观测到有效套筒接合，在稳定接合达到配置的物理步数后完成旋转，并使螺钉达到至少 21 mm 提取量（个别较早产物使用 20 mm 阈值，结果应按各自 summary 解释）。实现还跟踪接触、接合稳定性、螺钉旋转、最大提取量及安全终止原因。

## 4. 视觉估计

视觉模块不接收 MuJoCo 真值；仅输入 `uint8` RGB 图像。它提供目标中心、包围框、可见性、启发式置信度，以及腕部视角下螺钉中心相对工具尖端的像素偏移。

### 4.1 金属螺钉头检测

对 RGB 图像转换到 HSV 空间，以低饱和、一定亮度范围生成二值掩码，再通过 8 邻接连通域提取候选。候选根据面积区间、宽高、长宽比筛除。对轮廓计算紧致度：

\[
C = \min\left(1,\frac{4\pi A_c}{P^2}\right),
\]

其中 \(A_c\) 为轮廓面积，\(P\) 为周长。长宽比为 \(r=w/h\)，近方形分数为

\[
S=\exp(-|\log r|),
\]

面积分数为图像面积归一化后的截断值 \(A_s\)。最终启发式置信度为

\[
\gamma = \operatorname{clip}\bigl((0.48S+0.27C+0.25A_s)\,E,0,1\bigr),
\]

其中候选触边时边界因子 \(E=0.65\)，否则为 1。最高分候选在 \(\gamma\ge0.35\) 时标为可见。固定 `agentview` 使用目标 ROI 限定搜索范围；`wristview` 在全图搜索。该分数是几何/外观启发式，不是经概率校准的置信概率。

工具尖端位置来自腕部相机与工具之间的刚性标定像素坐标；局部金属像素占比给出尖端可见性提示。螺钉中心与尖端像素的差值构成局部视觉对准误差。

### 4.2 像素到平面反投影

当相机内参由图像高度和垂直视场角近似确定时，焦距（像素单位）为

\[
f = \frac{H}{2\tan(\phi/2)}.
\]

像素 \((u,v)\) 对应的相机射线（相机朝向沿负 z 的约定）为

\[
\mathbf r_c = \left[\frac{u-W/2}{f},-\frac{v-H/2}{f},-1\right]^T,
\qquad \mathbf r_w=R_{wc}\mathbf r_c.
\]

与已知高度平面 \(z=z_0\) 相交的参数为

\[
\lambda=\frac{z_0-t_{wc,z}}{r_{w,z}},\qquad
\mathbf p_w=\mathbf t_{wc}+\lambda\mathbf r_w.
\]

模块拒绝非正交/无效几何、平行射线及相机后方交点。此估计依赖已知螺钉头平面高度、相机标定和场景几何；高度误差会带来横向投影误差。另有深度输入版本按射线方向直接重建三维点。

## 5. 闭环控制方法

### 5.1 分层控制

高层策略决定任务阶段及目标位置；机器人适配层执行运动约束；仿真器处理刚体动力学与接触。启用的控制能力是显式选项，基础流程不会隐式假设力控或螺旋搜索已打开。任务推进遵循：粗定位 → 视觉对准 → 接触确认 → 顺应搜索/套接 → 稳定接合 → 旋转提取 → 成功/安全停止。

视觉 XY 对齐采用进入/释放双阈值，进入阈值 2 mm，锁定释放阈值 3 mm；视觉置信度至少 0.7 才允许用该视觉误差推进横向动作。该滞回避免误差在阈值边缘时反复切换锁定状态。策略目标单步笛卡尔增量上限为 5 cm；具体执行还受动作放大、路径插值和接触阶段限制。

### 5.2 力觉顺应接近

仿真包含末端力/力矩传感器。控制器对传感读数进行补偿后，以轴向力阈值（1 N）确认接触；面向力控的接近阶段根据垂直间隙逐步设定目标轴向力，目标设定值当前为 1 N。横向释放距离、满力区间和接近步长为显式常量，约束顺应阶段何时加力以及何时停止横向漂移。

这些数值是当前实现参数，不应理解为经真实 UR20 或真实紧固件验证的安全工作限值。

### 5.3 螺旋搜索与触觉接合

`spiral_search` 在轴向接触门控通过后执行。控制器在平面内生成逐步扩展的圆/螺旋搜索点，并以小段内部仿真步运行；期间保持受控轴向负载、记录补偿力/力矩与工具位移，形成在线触觉特征。搜索半径、角步进、目标力、旋转速率和最大点数由实现/运行配置决定，并记录在 metadata 或轨迹中。

可将平面搜索轨迹写为

\[
\mathbf p_{xy}(i)=\mathbf c + r_i
\begin{bmatrix}\cos\theta(t)\\\sin\theta(t)\end{bmatrix},
\]

其中当前实现使用 \(r_i=8\,\mathrm{mm}\cdot(i+1)/576\)，\(\theta_i=\theta_0+2\pi(16/3)i/576\)，最大搜索半径 8 mm、覆盖 576 个点。每个点套筒旋转 60°，并维持轴向顺应。就座检测要求从接触位置向下至少 3 mm，随后轴向力恢复到接触基线的至少 10%，并连续保持 20 个物理采样步。只有就座状态才允许 `turn_socket`。在线传感器门限仍未完成校准，因此不能把所有搜索成功归因于已校准的力觉分类器；部分实验由离线几何真值对接合状态作事后核验。

### 5.4 套筒旋转和提取

确认就座后，通过 MuJoCo 速度执行器旋转套筒，仿真中的套筒接触带动螺钉转动；螺旋约束随之产生轴向提取。执行阶段记录套筒接合、接触、轴向/径向误差、螺钉旋转角与抬升量。控制器依据提取阈值、稳定步数和安全条件结束，不以固定转动时间单独判定成功。

## 6. 数据流、复现与评测

### 6.1 单回合与基准

单回合 runner 固定一个 `state_id`，设置模型/配置、最大策略调用数、最大仿真步数、请求超时和输出目录。10 状态 benchmark 顺序运行 `state_id=0..9`，每个状态分目录写入独立记录。真实 API 调用需要显式 `--execute-paid-rollouts`；力反馈、顺应控制和螺旋搜索也通过显式参数开启。

常见产物包括策略 transcript、API usage、动作 JSONL、summary、视频、螺旋力迹及元数据。确定性 replay 可重放保存的工具决策，不产生新的模型调用，适合区分“策略决策是否可复现”和“环境执行是否完成”。

### 6.2 指标

核心任务指标：

- 成功率：有效提取回合数 / 有效回合数；
- 提取量：最大螺钉轴向位移（m）；
- 套接可靠性：是否出现有效接合、稳定接合步数、就座确认；
- 效率：模型调用数、仿真/物理步数、实际费用和墙钟时间；
- 控制质量：最大横向误差、接触力迹、套筒轴向/径向误差；
- 运行完整性：超时、预算停止、安全停止、worker 故障等分类。

正式比较应使用同一初始状态集合、相同策略预算和一致控制选项，并报告每状态结果及汇总统计；不可把不同状态数、不同控制能力或不同预算的记录直接当作公平模型排名。

## 8. 复现流程

基础环境使用 Python 3.10+，安装项目及开发依赖，配置对应 API profile；无头 Linux 可设置 `MUJOCO_GL=egl`。建议按以下顺序复现：

1. 运行本地 worker/mock 检查，确认场景、观测和动作接口连通；
2. 运行视觉评测/场景检查，核对目标 ROI 和像素标定；
3. 用一个固定 `state_id` 执行完整回合，显式选择力控、顺应和搜索开关；
4. 检查 summary、动作轨迹、力迹和视频；
5. 再运行 10 状态基准，并逐状态保留结果。

场景生成入口为 `scripts/scene/build_screw_scene.py`；目标配置集中在 `src/ur20_screw/target.py`。注意场景 XML、目标高度/ROI 和网格资产必须保持一致。

## 9. 局限与适用范围

1. **理想化紧固件物理。** 螺纹用线性螺旋约束替代，不含真实牙型啮合、摩擦、滑牙和壳体变形，因而旋出时间、扭矩和接触稳定性不等价于真实作业。
2. **视觉依赖场景外观。** HSV 金属检测、固定 ROI、工具尖端像素标定和已知平面投影均为场景特定启发式；光照、遮挡、背景材料和相机安装变化需重新验证。
3. **力觉触觉尚需完整校准。** 代码实现传感器补偿、门控和触觉摘要；可用记录明确显示部分在线门限校准仍未完成。
4. **统计证据有限。** 已见单状态成功与重放成功，不能代替全部 10 个初始状态、多模型、多随机扰动的重复评测。
5. **仿真到现实迁移未证明。** 仿真传感器、接触参数、UR20 动态和控制链路需与真实硬件标定；当前报告不声称真实机器人验证。

## 10. 后续研究与验证

最能增强证据的工作是完成统一配置下的 10 状态闭环基准，公布逐状态成功、提取量、调用/费用、失败阶段及置信区间；随后做分阶段消融（视觉门控、力反馈、顺应接近、螺旋搜索），并对每一项使用相同状态和策略预算。应对触觉门限进行独立校准集与留出验证，报告接合检测的精确率/召回率及误触发代价。最后，对相机位姿、光照、横向初始偏差和接触参数做受控扰动，确定视觉与控制模块的有效范围。
